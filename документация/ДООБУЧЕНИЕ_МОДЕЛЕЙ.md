# Дообучение моделей Polybot

## Безопасный порядок

1. `python подготовить_дообучение.py`
2. Проверить `preparation_report.json` в новом `данные/подготовленные_обучения/training_bundle_*`.
3. `python дообучить_модели.py`
4. Проверить offline-метрики challenger-моделей.
5. Только прошедшие gate модели запускать сначала в shadow, затем в PAPER.

Подготовка использует SQLite backup: сборщик и PAPER-торговля продолжают работать.
Рабочие модели автоматически не заменяются.

## Разделённые задачи

- `direction`: вероятность официального Up/Down. Использует текущий график и завершённые 3/12 событий.
- `entry_value`: `P(fill) × E(net PnL | fill)` после комиссии.
- `sizing`: выбор лимитной цены и размера от $1 до $10.
- `exit`: HOLD, полный либо частичный выход 20/40/60/80/100%.
- `fill`: вероятность исполнения заявки в реалистичном стакане.

Нельзя обучать одну модель только на фактически совершённых сделках: это создаёт selection bias.
Поэтому bundle содержит фактические сделки и контрфактические действия, включая пропущенные входы.

## Валидация

Train/validation/test разделяются хронологически по целым событиям. Между границами удаляются
по два события. Снимки одного события никогда не попадают в разные части выборки.

Кандидат не допускается дальше offline-стадии, если:

- нижняя 95% граница среднего PnL не положительна;
- недостаточно независимых OOS-событий;
- отсутствует достаточное число Up и Down сделок;
- ухудшились Brier/ROC-AUC/PR-AUC или калибровка;
- есть direction collapse;
- прибыль исчезает после комиссии, fill/non-fill и глубины стакана.

## Qwen / QLoRA

Рекомендуемый первый эксперимент:

```powershell
python служебные_скрипты/train_qwen_qlora.py --bundle "ПУТЬ_К_BUNDLE" --task direction
```

Direction-only выбран намеренно. Текущие экономически оптимальные BUY-action метки сильно
односторонние; искусственная замена Up/Down создала бы ложный датасет. Направление обучается
на сбалансированной официальной разметке, а цену, WAIT и размер выбирает value-модель.

Exit-LoRA запускается отдельно:

```powershell
python служебные_скрипты/train_qwen_qlora.py --bundle "ПУТЬ_К_BUNDLE" --task exit
```

Для QLoRA нужны NVIDIA CUDA, CUDA-версия PyTorch и `bitsandbytes`. CPU/CatBoost/custom
обучаются командой `python дообучить_модели.py`.
