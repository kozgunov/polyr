# Polybot local

Локальная система сбора BTC Up/Down 5m, разметки и безопасной demo-торговли.
Реальные ордера сейчас технически заблокированы.

## Папки

- `данные` — SQLite, CSV-экспорты и артефакты моделей;
- `документация` — инструкции и аудит подключений;
- `журналы` — stdout/stderr процессов;
- `запуск` — диагностика, dashboard, collector, экспорт и обучение;
- `исходный_код/polybot` — код приложения;
- `настройка_проекта` — зависимости;
- `примеры` — примеры входного контекста;
- `служебные_скрипты` — вспомогательные сценарии;
- `тесты` — unit/integration тесты.

В корне намеренно оставлены `app_config.py`, `api_config.py` и два ручных
торговых лаунчера.

## Ручной запуск

```powershell
.\.venv\Scripts\python.exe .\запустить_демо.py
.\.venv\Scripts\python.exe .\запустить_реальную_торговлю.py
```

Второй файл не умеет отправлять ордера: он проверяет статистические критерии,
kill switch и настройки, после чего всё равно останавливается до отдельного
аудита реального order executor.

Сборщик и dashboard:

```powershell
.\запуск\start_continuous_collector.ps1
.\запуск\start_dashboard.ps1
```

Экспорт данных для Excel/VS Code:

```powershell
.\.venv\Scripts\python.exe .\запуск\экспортировать_данные.py
```

Файлы появятся в `данные\экспорт_для_просмотра`.

## Проверки

```powershell
.\.venv\Scripts\python.exe -m pytest -c .\исходный_код\pyproject.toml .\тесты
.\.venv\Scripts\python.exe -m pip check
```
