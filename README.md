# PolyR — исследовательский бот для BTC Up/Down 5m на Polymarket

Локальная система сбора данных, PAPER/LIVE-исполнения, обучения моделей и мониторинга через дашборд. По умолчанию проект запускается безопасно: LIVE выключен, а kill switch включён.

## Быстрый запуск на новом компьютере

1. Установить Python и Git.
2. Клонировать репозиторий.
3. Создать окружение и установить зависимости:

   ```powershell
   py -m venv .venv
   .\.venv\Scripts\python.exe -m pip install -U pip
   .\.venv\Scripts\python.exe -m pip install -r .\настройка_проекта\requirements.txt
   ```

4. Скопировать `api_config.example.py` в `api_config.py` и локально заполнить необходимые поля.
5. Восстановить базу и веса моделей из отдельного снимка переноса — они намеренно не хранятся в Git.
6. Запустить все локальные сервисы одной командой:

   ```powershell
   .\.venv\Scripts\python.exe .\запустить_проект.py
   ```

Дашборд по умолчанию доступен на `http://127.0.0.1:8765/`.

## Структура

- `исходный_код/polybot/` — сборщики, модели, торговый движок, аналитика и дашборд.
- `запуск/` — отдельные точки запуска и диагностики.
- `тесты/` — автоматические проверки исполнения, комиссий, моделей и панели управления.
- `служебные_скрипты/` — аудит, обучение, эксперименты и экспорт.
- `настройка_проекта/` — зависимости и план перехода на GPU.
- `документация/` — архитектура, стратегия, перенос и эксплуатация.
- `данные/` и `модели/` — локальные runtime-артефакты, не публикуются в Git.

## Безопасность

`api_config.py`, приватные ключи, CLOB credentials, Telegram-токены, базы, логи и веса исключены через `.gitignore`. Перед первым LIVE-запуском отдельно проверьте кошелёк, лимиты, kill switch и диагностические тесты. Положительные PAPER-результаты не гарантируют прибыль в LIVE.

Подробный перенос состояния описан в [README_ПЕРЕНОС.md](README_ПЕРЕНОС.md).
